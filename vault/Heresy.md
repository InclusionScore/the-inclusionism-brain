# Heresy

## Definition

A deviation from an established value system that proposes an alternative framework for meaning, belonging, or participation.

---

## Inclusionist Perspective

Heresy functions as innovation within value-distribution systems.

Orthodoxy preserves stability.

Heresy introduces adaptation.
