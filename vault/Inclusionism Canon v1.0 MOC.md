# Inclusionism Canon v1.0

## Foundational Axiom

We have intrinsic value.

We derive that value through our interactions with one another.

We are entitled to equity in the value that proliferates from those interactions.

---

## Inclusionist Social Dynamic

Interaction
→ Value
→ Recognition
→ Agency
→ Legitimacy
→ Fairness
→ Belonging
