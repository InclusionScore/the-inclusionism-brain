# Personal Data

## Definition
Personal data is metadata that derives from living and non-living individuals through existence, interaction, participation, and transaction within systems.

---

## Inclusionist Perspective
All data is a derivative of personal data because all data originates from interactions involving identifiable entities, systems, environments, or participants.

Data is not merely stored information.

Data is the observable residue of relational existence.

---

## Core Principle
Participation generates data.

---

## Inclusionist Perspective
Existence within civilization inevitably produces informational traces.

These traces:
- enable coordination
- influence value emergence
- shape institutions
- train AI systems
- construct identity
- influence governance
