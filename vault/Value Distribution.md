# # Value Distribution

## Definition

The processes through which value generated by interactions is recognized, attributed, allocated, and transferred among participating agents.

---

## Inclusionist Perspective

Every civilization contains value distribution systems.

The central question is not whether value will be distributed.

The question is how accurately distribution reflects participation in value creation.

---

## Core Principle

The legitimacy of a civilization depends partly upon the legitimacy of its value distribution systems.

---

## Inclusionist Perspective

Failures in value distribution often manifest as:

- poverty
    
- exclusion
    
- instability
    
- concentration of power
    
- declining trust
    
- reduced participation
