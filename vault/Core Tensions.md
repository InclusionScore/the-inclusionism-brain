# Core Tensions

| Tension | Description |
|---|---|
| Inclusion vs Efficiency | Broad participation can increase coordination complexity |
| Centralization vs Decentralization | Efficiency versus distributed resilience |
| Automation vs Meaning | Productivity versus participatory purpose |
| Connectivity vs Individuality | Network integration versus autonomy |
| Transparency vs Privacy | Coordination versus personal sovereignty |
| Stability vs Adaptation | Order versus evolutionary flexibility |
| Optimization vs Humanity | System efficiency versus lived experience |
| Intelligence vs Wisdom | Capability versus ethical direction |
| Globalization vs Belonging | Planetary coordination versus local identity |
