# # Data Dividend

## Definition

A mechanism through which individuals receive value derived from data generated through their participation in social, economic, technological, or informational systems.

---

## Inclusionist Perspective

Personal data emerges through interaction.

The value generated from that data may therefore create legitimate participation claims.

---

## Core Principle

Participation in data generation may justify participation in resulting value creation.

---

## Inclusionist Perspective

Data Dividends represent an early attempt to improve relational attribution within digital economies.
